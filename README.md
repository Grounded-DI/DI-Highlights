# DI-Highlights — 2025 Reports, Demonstrations, and Captures

## Overview

This repository collects notable Grounded DI reports, demonstration screenshots, and dated public-record materials. It includes a July integrity report, a June tornado-detection timeline, an AGIA sweep report, and screenshots of legal, finance, quantum, health-research, and patent-analysis interfaces.

The README identifies which statements are report contents, which records are screenshots, and where the included evidence stops.

- BriefWise outperformed leading legal GPTs.

Those are the report’s recorded performance statements. The repository does not include benchmark datasets or comparative study materials for independently recalculating them.
